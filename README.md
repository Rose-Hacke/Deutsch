# AfD历史叙事与身份动员研究材料

本仓库保存《历史叙事与身份动员：AfD在东部德国争取选民支持的机制——以萨克森—安哈尔特州为例》的研究材料与方法初稿。

**全部语义判断仍为AI初编，尚未人工复核。暂定工作范围：2025年1月1日至2026年9月6日。**

目前整理了19份已定年核心文本及1份会议日期待核的补充发言，选定70个意义单元，形成840项编码判断，其中16项待决。这些文本分析不能直接证明选民接受或选举效果。
