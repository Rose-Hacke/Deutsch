# 初步叙事备忘录：AI初编，待人工复核

暂定工作范围：2025年1月1日至2026年9月6日。当前核心为19份已定年文本的57个选定意义单元，另有日期待核的议会发言13单元。以下只说明文本怎样组织主张，不推断选民接受或选举效果。

“不公与贡献相结合”获得局部支持，但其共同体指向需要修正。纲领先把罪责记忆和六八运动描为民族自信受损的原因，再让AfD承担“治愈”认同的角色，并将亨利、奥托、路德、俾斯麦、尼采及语言遗产组织成州对德国的贡献。这条跨段链以文化导言及同一节的明确回指相连，较接近“受损认同—历史资源—修复者”路径；对象主要是德国民族及州的国家历史地位，不能直接改写为东部物质受害。（C01）

东部框架有另一结构：文本先否定将东方描为缺陷地区的看法，再称东方是“更好的德国”，并以革命经验解释今日政治警觉。但“革命”没有年份，AfD政府传播战略也未明确等于代表资格。因此，这条链在历史事件和代表环节仍不完整；被转述的经济弱势更不能当成作者认可的不公事实。（C02）

5月8日署名文章提供更直接的连接：它承认纳粹受迫害者获得解放，同时拒绝以民族灾难为代价的庆祝；随后批评永久集体罪责，赞扬民族能力，明确将AfD的民族情感复兴与有效利益代表相连。但这里仍是德国民族，而非专指东部选民。（C05）

反例限制了普遍机制解释：RAF类比主要组织政治受害而无贡献肯定；地方党员自豪不依靠历史；投票号召可以没有F1或F2；教会历史则被用于家庭规范。另有文章直接为记忆选择性辩护，提示文化制度控制、民族正常化和旅游品牌也是替代解释。（C06—C11）

核心57单元中，F1/F2可决的53单元分别有14个只有F1、12个只有F2、6个二者都有、21个二者皆无，另4个待决。同文共现不等于语义相连，长纲领也不是多份独立证据。结论仍处于目的性样本的AI解释阶段。
