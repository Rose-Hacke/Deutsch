## 核心解释与边界

部分文本支持“受损认同／承认—贡献或民族肯定—AfD修复与代表资格”的连接，尤其是纲领的文化论证与P_LV_1227的5月8日文章。但不少主张指向德国民族、州共同体、党组织或基督徒，不能统一改成东部德国人。明确的东部段落含“更好的德国”及革命经验，却未给革命年份，其代表环节也仍存疑问。

反例包括只有政治不满、只有党组织自豪、没有历史前提的代表资格与投票号召，以及宗教传统服务家庭规范的路径。没有据文本证明真实选民接受，也未证明叙事导致得票增长。党派引用的调查、暴力指控和历史名言归属未当作独立外部事实证据。

统计见[code_distribution.csv](code_distribution.csv)、[F1/F2四类比较](f1_f2_comparison.csv)、[来源×代码矩阵](source_code_matrix.csv)及[同单元共现](code_cooccurrence.csv)。核心57单元中F1与F2均可决者53个：只有F1为14，只有F2为12，兼有6，均无21，另4个待决。核心来源层面可决18份：只有F1为9、只有F2为4、兼有2、均无3，另1份待决。**来源共现不能替代语义连接。**各表明确分开独立来源、编码单元与有效分母，不对目的性样本作总体推断或显著性检验，多重编码不加总为100%。
